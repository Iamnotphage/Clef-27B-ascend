- 以 `ao/docs-new-handoff/perf-next`（`df7cb1a`）为基线，在官方入口 `bash start.sh --config s1` 上完成了重新 profile、S2 调度复测、GDN chunk 扩展扫描、joint head CPU 分解与 prefix caching 评估。

## 3. S2 调度复测

历史配置已把 token 预算与批一起放大（B8→8192、B16→16384、B32→32768），backlog 中“4096 未扫”的前提已过时。本窗口复测并补一个“预算是否绑定”的对照：

| 配置 | 并发 | dec/s | mean ms | p95 ms | 结论 |
| --- | ---: | ---: | ---: | ---: | --- |
| B8 / 8192 | 16 | 16.738 | 952.4 | 1772.1 | 与历史 16.727 一致 |
| **B16 / 16384** | 64 | **17.462** | 3628.8 | 5945.8 | 与历史 17.446 一致，仍为最优点 |
| B16 / 24576 | 64 | 17.374 | 3647.4 | 5986.5 | 预算不是约束，放大无收益 |
| B32 / 32768（历史） | 128 | 17.364 | 7221.2 | 10510.6 | 已饱和 |

吞吐在 17.4–17.5 decisions/s 饱和，瓶颈是设备 compute（批内 M 已足够大、权重读取被摊薄），不是调度。**维持 B16 C64 / 16384 作为上报点，B8 C16 作为低延迟点。**

## 5. joint head / pooler CPU 分解（负结果）

在单字段 postimage 内加入 `CLEF_JOINT_TIMING=1` 门控打点（默认关闭；测后已 `git checkout` 还原，SHA 回到 `f8101b98…`，安装器 `--check` ready），967 token、4 候选：

| 段 | ms（每请求） |
| --- | ---: |
| `parse_joint_schema` | 0.01 |
| `_indices`（numpy + H2D） | 0.23–0.28 |
| `lexical`（embed + segment_mean） | 0.62–0.71 |
| **head 合计** | **4.78–5.05** |
| ↳ `norm_mem`（LayerNorm 967×5120 + memory 投影 + segment_mean） | 0.24–0.27 |
| ↳ `options`（3 投影 + 2 层 evidence routing） | 1.09–1.18 |
| ↳ `fields_route` | 0.42–0.45 |
| ↳ `decoder`（4 层单字段解码器） | **2.23–2.33** |
| ↳ `final`（field_norm + prior/cosine/residual） | 0.62–0.67 |
| `act`（softmax + 收集） | 0.15–0.17 |
| pooler 合计 | 5.90–6.25 |

- 结构上约 100 个小算子，`decoder` 每层约 15 个（3 norm + 2 自注意力投影 + 跨注意力 in/attn/out + FFN 3 + 4 残差），耗时与 FLOP 无关，全部是下发开销。设备侧对应算子合计仅约 1.5–2 ms（LayerNormV4 6 µs、Index 36 µs、ZerosLike 9 µs 量级）。
- **CPU 卸载否决**：`memory_projection` 是 967×5120×1024 ≈ **10.1 GFLOP**，必须留在 NPU；搬到 CPU 的剩余部分仍有约 70 MFLOP（4 层 FF 4096 + 2 层 routing 跨注意力）且在 `OMP_NUM_THREADS=1` 下估算 3–4 ms，加上 9.9 MB D2H（约 0.4 ms），净收益不足且数值路径改变。
- 跨请求批处理已在 2026-11-16 实测无 S2 收益（`docs/joint-head-batch-2026-11-16.md`）。
- 结论：**joint head 维持现状**；再降需要把整个 head 融合成 Ascend C 算子，工作量与本轮时间窗不匹配。

## 6. prefix caching（负结果）

- 关闭 chunked prefill 时直接拒绝启动：`pydantic ValidationError: Chunked prefill is required for Mamba prefix caching`。
- 打开 chunked prefill 会关闭 GDN 决策快速路径，并且决策头的 span 语义建立在“本次前向包含完整 prompt”之上；公共前缀仅约 45 token，收益上限远小于该组合的风险。
- **不启用**；`--no-enable-prefix-caching` 维持固定。
