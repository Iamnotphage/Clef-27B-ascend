## 目的与协议

ERQA 官方 400 题、固定引擎批配置 `max_num_seqs=16`，使用
`src/runtime/erqa_s2_concurrent.py`（有界并发版 frozen runner）扫描
`C=8/16`，取最大有效 decisions/s。

- 服务：同一 OD→ERQA 进程 PID 734299，启动时间 `2026-11-26T00:41:59Z`，
  未重启；
- 环境：`quay.io/ascend/vllm-ascend:v0.30.0-a3`、A3 1 物理卡 2 逻辑设备、
  BF16、TP2、eager；
- 配置：`max_model_len=16384`、`max_num_seqs=16`、`max_num_batched_tokens=16384`、
  `image=16`、`encoder_cache_tokens=262144`、Tier 2 window=500、
  `TASK_QUEUE_ENABLE=2`；
- 接口：`state-list` / `POST /systemone`；
- 数据：`/tmp/final-test-erqa-data`（官方 400 题）；
- 服务已由 ERQA S1 正式轮预热；本轮 C8/C16 直接热态测量，不再单独 warmup；
- runner 每个请求只允许一次尝试（`retries=1`，attempts==1），0 失败/重试。

## 结论

- **最大有效点：C16，三次平均 21.439 dec/s**（中位 21.863、最大 22.246）；
  R3 有一个约 2.1 s 的尾部离群，故平均低于中位，但 p50 仍约 694 ms。
- C8 平均 17.821 dec/s、p95 476.8 ms；吞吐明显低于 C16，但 p95 约为 C16 的 58%。
- C16 三次预测逐题一致；C8 与 C16 有 4/400 预测差异（批组成导致），
  accuracy 均为 **216/400 = 0.540**，与历史 ERQA S2 一致，2PP 内。
- 与历史 ERQA C16（21.355/22.302 dec/s、216/400）基本一致。
