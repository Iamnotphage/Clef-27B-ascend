## 结论

- **最大有效吞吐：B16 C64 = 21.583 decisions/s（三次平均，0 失败）**，
  与官方历史 21.607 dec/s / p95 3961.8 ms 基本一致。
- C32 为 21.544 dec/s（仅低 0.2%），但 p95 2,068.9 ms，约为 C64 的一半；
  若赛方对 p95 有约束，C32 是更稳的选择。
- C128 已饱和：21.560 dec/s，p95 7,375.4 ms，无收益。
- B8 未在本轮复测；仓库历史 B8 C16 约 16.7 dec/s，低于 B16 C64。
